# Bump brscan5 from 1.5.1 to 1.6.2

## Context
CI failed because `build_files/build.sh` pins the brscan5 RPM URL to version 1.5.1. Brother removed that RPM from their CDN after releasing 1.6.2. The curl downloaded a 10-byte error page instead of the RPM, causing the build to fail with `error: open of Not failed`.

## Alternatives Considered
- **Pin to floating `latest` URL**: Brother URLs use a numeric download ID (`dlf104036`) that is stable across versions, but the filename includes the version number. No redirect is served.
- **Use AUR PKGBUILD or void-linux template**: Both upstreams already use 1.6.2 (confirmed).
- **Skip the version entirely**: Not feasible — the scanner won't work without the driver.

## Rationale
1.6.2 is the current version in both void-linux (`srcpkgs/brother-brscan5`) and AUR (`brscan5`). The same download ID (`dlf104036`) works. No API or packaging changes are needed.

## Requirements
1. Update the download URL in `build_files/build.sh` from `brscan5-1.5.1-0.x86_64.rpm` to `brscan5-1.6.2-0.x86_64.rpm`.
2. Update references in `spec/2026-05-31-08-brscan5_scanner.md`.
3. Build the image locally and verify `rpm -q brscan5` reports version 1.6.2.

## Technical Approach
Single-version bump in the hardcoded URL. The RPM post-install behavior is identical; no other files modified.
