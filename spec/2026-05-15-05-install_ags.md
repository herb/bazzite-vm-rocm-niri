# Install AGS (Aylur's GTK Shell) via COPR

## Context

The custom Bazzite image adds Niri as an alternative window manager. AGS
provides a customizable widget shell (bars, notifications, app launchers)
making the Niri desktop more functional and visually polished.

AGS is not available in the main Fedora repos. The install options are:
building from source (npm+meson+go) or installing from a community COPR.

## Alternatives considered

| Approach | Reason rejected |
|----------|----------------|
| Build from source inline in build.sh | Build deps (golang, meson, npm) bloat the final image; longer build times; no update path |
| Multi-stage Containerfile build | More complex; fragile to upstream API changes |
| `aneagle/ags-3` COPR | Less established; maintained by an individual; `solopasha` is referenced by the AGS wiki itself |

## Rationale

The `solopasha/hyprland` COPR is the recommended Fedora installation method
on the AGS documentation. It provides RPMs for Astal libraries + AGS itself,
auto-handles dependencies, and updates come through normal `dnf update`.

## Requirements

- AGS (version 2, `aylurs-gtk-shell2`) is installed in the image.
- The COPR repo is added so updates can be pulled in future builds.
- No unnecessary Hyprland packages are pulled in as transitive deps.
- The image builds successfully.

## Technical approach

### COPR repository

Enable the `solopasha/hyprland` COPR and install the package:

```bash
dnf5 config-manager addrepo --copr solopasha/hyprland
dnf5 install -y aylurs-gtk-shell2
```

### Startup (deferred)

AGS requires per-user config at `~/.config/ags/`. Starting it without config
would log errors but not crash. A systemd user service was created at
`services/ags.service` (available in the image but NOT auto-enabled). To
enable when ready:

```bash
systemctl --user enable --now ags.service
```

## Issues & Resolutions

| Issue | Resolution |
|-------|-----------|
| `ags` binary path uncertainty (v2 Go binary vs v1 GJS script in COPR) | Confirmed via `solopasha/hyprland` COPR spec that v2 produces `/usr/bin/ags`; service points there |
| AGS has no upstream systemd user service to reference | Created one following the pattern of existing `services/swayidle.service` and `services/plasma-polkit-agent.service` |
